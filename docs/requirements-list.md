> 记录时间：2026-04-17

## 项目目标

让 AI 能高质量地完成「设计稿 → 安卓运行时」的实现，并提供设计稿与运行时的视觉核对与循环修正能力。

---

## 核心功能模块

### 1. 设计稿预处理（HTML/CSS → 结构化文档）

- 为设计稿 HTML 的每个节点自动注入唯一 `id`
- 使用 BeautifulSoup 解析渲染后的 DOM，提取每个节点的：
  - 位置（x, y）
  - 尺寸（width, height）
  - 属性信息（颜色、字体、padding 等）
- 选定一个「锚点节点」，其余所有节点存储相对锚点的相对位置/尺寸信息
- 输出结构化文档（JSON/YAML），作为后续实现的基准

### 2. AI 编码实现

- 以上述结构化文档为基准，AI 生成对应的安卓视图代码
- 运行 App 并导航到对应页面

### 3. 运行时叠加对比（WebView 叠加）

- 通过客户端 SDK 将设计稿 HTML 加载到当前页面的 WebView 上
- 支持手动调整 WebView 的上下左右偏移
- 支持调整 WebView 透明度
- 用户手动对齐锚点位置

### 4. AI 自动差异计算与校正（核心循环）

- AI 通过 SDK 获取：
  - WebView 中 DOM 树相对屏幕的结构化数据
  - 原生页面 View 树相对屏幕的结构化数据
- 计算 DOM ↔ View 的差异（位置、大小）
- 针对不同组件类型（text、list 等）有各自的自定义核对属性
- 逐步运行时调整 View 的属性（margin、padding 等），直到满足验收标准
- 这是一个「获取差异 → 调整 → 再校验」的循环过程

### 5. 运行时属性修改能力

- 通过常用属性（margin、padding、gravity 等）实时修改 View
- 修改后立即触发重新校验

---

## 验收标准（初步）

- DOM 节点与对应 View 节点的位置误差在可接受阈值内
- 不同组件类型的核对维度可自定义配置
